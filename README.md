# Wordle — игра в слова на Java

Java-приложение для игры в Wordle на русском языке. Игрок угадывает слово из 5 букв за 6 попыток, получая подсказки по буквам и запрашивая дополнительные слова из словаря.

![Java](https://img.shields.io/badge/Java-17+-blue)

---

## Возможности

- 🎯 **Угадывание слова из 5 букв** за ограниченное число попыток.
- 🐂🐄 **Подсчёт быков и коров** — точных попаданий и букв не на своём месте.
- 💡 **Подсказки** — случайное неиспользованное слово из словаря.
- 📖 **Загрузка словаря из файла** с нормализацией (обрезка пробелов, `ё → е`, нижний регистр).
- 📝 **Логирование** всех ходов и событий игры в файл `wordle.log`.
- 🚫 **Защита от повторов** — нельзя ввести одно слово дважды.
- ✅ **Проверка слова по словарю** — принимаются только существующие слова.

## Структура проекта

| Класс | Назначение |
|---|---|
| `Wordle` | Точка входа: меню, игровой цикл, взаимодействие с пользователем |
| `WordleGame` | Логика одной партии: загаданное слово, попытки, проверка ходов |
| `WordleDictionary` | Хранит список слов, выдаёт случайное слово, проверяет наличие |
| `WordleDictionaryLoader` | Загружает словарь из файла с нормализацией |
| `MoveResult` | Результат хода: быки, коровы, статусы букв |
| `LetterStatus` | Enum: `BULL`, `COW`, `ABSENT` |
| `DictionaryLoadException` | Ошибка загрузки словаря |
| `WordNotFoundInDictionary` | Слово отсутствует в словаре |
| `WordAlreadyUsedException` | Слово уже было использовано |

### Ответственности классов

| Класс | Что делает | Чего **не** делает |
|---|---|---|
| `Wordle` | Меню, чтение ввода, вывод результата | Не хранит состояние игры |
| `WordleGame` | Загадывает слово, считает быков/коров, ведёт счёт попыток | Не работает с файлами и консолью |
| `WordleDictionary` | Хранит слова, отдаёт случайное, проверяет наличие | Не знает про игру |
| `WordleDictionaryLoader` | Читает файл, нормализует слова | Не хранит состояние партии |
| `MoveResult` | Хранит результат одного хода | Не считает сам себя |
| `LetterStatus` | Enum статусов букв | — |

## Ключевые решения

### 1. Разделение состояния игры и интерфейса

`WordleGame` ничего не знает о консоли — только о словаре, логе и загаданном слове.
`Wordle` занимается вводом/выводом и вызывает методы игры.

Почему именно так:

- Логику игры можно тестировать без эмуляции консоли.
- UI легко заменить (консоль → веб → GUI).
- `WordleGame` остаётся детерминированным, если передать слово через конструктор.

### 2. Два конструктора `WordleGame`

```java
public WordleGame(WordleDictionary dictionary, PrintWriter log) {
    this(dictionary.getRandomWord(), dictionary, log);
}

public WordleGame(String answer, WordleDictionary dictionary, PrintWriter log) {
    ...
}
```

Второй конструктор — для тестов: можно зафиксировать загаданное слово и
проверять конкретные сценарии без случайности.

### 3. Алгоритм подсчёта быков и коров в два прохода

```java
// Первый проход — быки
for (int i = 0; i < s.length; i++) {
    if (s[i] == g[i]) {
        bulls++;
        s[i] = '#';
        g[i] = '#';
    }
}

// Второй проход — коровы
for (int i = 0; i < g.length; i++) {
    ...
}
```

Два прохода нужны, чтобы буквы, уже засчитанные как быки, **не учитывались повторно**
как коровы. Символ `'#'` используется как маркер «буква уже обработана».

Почему не в один проход:

- Если сначала считать коров, можно «потратить» букву, которая на самом деле бык.
- Классический пример: `secret = "ааббв"`, `guess = "ааааб"` — три `а` в догадке,
  но только две в секрете.

### 4. Нормализация слов в одном месте

```java
trimmed.toLowerCase(Locale.ROOT).replace('ё', 'е')
```

Всё, что попадает в словарь, и всё, что вводит игрок, проходит одну и ту же
нормализацию. Это гарантирует, что `Ёлка`, `ёлка` и `елка` — одно и то же слово.

`Locale.ROOT` — чтобы `toLowerCase` не зависел от локали системы (в турецкой
локали `I` → `ı`, что сломало бы сравнение).

### 5. `HashSet` для быстрых проверок

```java
private final Set<String> usedWords = new HashSet<>();
private final Set<String> usedHints = new HashSet<>();
```

- `usedWords.contains(word)` — O(1) вместо O(n) по списку.
- `usedHints` не даёт выдать одну и ту же подсказку дважды.

### 6. Кастомные исключения с полезной нагрузкой

```java
public class WordNotFoundInDictionary extends Exception {
    private final String word;
    public String getWord() { return word; }
}
```

Исключение несёт само слово — не нужно парсить сообщение, чтобы его достать.
В `Wordle` это используется для понятного вывода пользователю.

### 7. Логирование через `PrintWriter`

Один `PrintWriter` создаётся в `main` и передаётся во все классы. Это:

- Единый лог-файл `wordle.log`.
- Нет открытия/закрытия файла на каждый ход.
- try-with-resources гарантирует закрытие при выходе.

## Методы `WordleGame`

| Метод | Что делает |
|---|---|
| `makeMove(String word)` | Проверяет слово, считает быков/коров, обновляет счётчик попыток |
| `isOver()` | true, если игра выиграна или попытки кончились |
| `isWin()` | true, если слово угадано |
| `getSteps()` | Сколько попыток осталось |
| `getAnswer()` | Загаданное слово |
| `getHint()` | Случайное неиспользованное слово или `null` |

## Методы `WordleDictionary`

| Метод | Что делает |
|---|---|
| `getRandomWord()` | Случайное слово из словаря |
| `contains(String)` | Есть ли слово в словаре |
| `getWords()` | Весь список слов |

## Пример использования

```java
WordleDictionary dictionary;
try (PrintWriter log = new PrintWriter("wordle.log", StandardCharsets.UTF_8)) {
    WordleDictionaryLoader loader = new WordleDictionaryLoader("words_ru.txt");
    dictionary = loader.getWords();

    WordleGame game = new WordleGame(dictionary, log);

    while (!game.isOver()) {
        String guess = "кранч"; // в реальной игре — из консоли
        WordleGame.MoveResult result = game.makeMove(guess);

        System.out.println("Быков: " + result.getBulls()
                + ", коров: " + result.getCows());
    }

    System.out.println(game.isWin()
            ? "Победа! " + game.getAnswer()
            : "Проигрыш. Было: " + game.getAnswer());
} catch (DictionaryLoadException | WordNotFoundInDictionary
         | WordAlreadyUsedException e) {
    System.err.println(e.getMessage());
}
```

## Формат ввода в консоли

- Слово из 5 букв (регистр не важен, `ё` = `е`).
- `подсказка` — запросить подсказку.
- Пустая строка — игнорируется.

Вывод результата хода:

- `[Б]` — бык (буква на своём месте).
- `(к)` — корова (буква есть, но не там).
- ` а ` — буквы нет в слове.
